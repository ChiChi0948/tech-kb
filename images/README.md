# images/

放節點頁用的截圖與圖解。

1. 檔名用 `節點id-編號.webp`，例如 `cowos-1.webp`、`hbm-2.webp`。
2. 先壓縮：建議 .webp、寬度 1200px 以內、單張 300KB 以下，repo 才不會越來越肥。
3. 到 `assets/data.js` 的 `figures` 登記一筆：
   `{ node:"cowos", src:"images/cowos-1.webp", caption:"一句話說明", source:"出處名稱", url:"原始網址" }`
4. `source` 和 `url` 一定要填：這個網站是公開的，每張圖都要標明出處。
