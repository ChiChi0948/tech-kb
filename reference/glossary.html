術語速查表

供應鏈研究中常見的關鍵術語。學到新名詞就加進來。

Fabless無廠半導體公司，只做 IC 設計、不蓋廠，把製造外包給代工廠。例：輝達、高通。
Foundry晶圓代工廠，替別人製造晶片但不做自有品牌。例：台積電。
IDM整合元件製造商，設計與製造一手包。例：英特爾、三星。
OSAT委外封裝測試廠，負責晶片的封裝與測試。例：日月光。
HBM高頻寬記憶體，垂直堆疊 DRAM 提供高頻寬，AI 運算關鍵。
CoWoS台積電的先進封裝技術，把 GPU 與 HBM 整合在矽中介層上。
EUV極紫外光刻，做先進製程必備，設備全球僅 ASML 能造。
SoC系統單晶片，把 CPU/GPU/基頻等整合在一顆晶片，手機核心。
製程節點 (Node)如 3nm/5nm，數字越小通常代表電晶體越密、效能功耗越好。
HDI高密度互連板。用雷射微孔與細線路逐次積層，在小面積完成大量連接。見 HDI 頁。
HDI 階數逐次積層加微孔互連做了幾輪；寫成 X+N+X（中間 N 層芯板、兩側各積層 X 輪）。與 PCB「層數」是不同概念。
逃線 (Fan-out)把線路從晶片底部密集焊點之間引出來的過程；焊點越密越難，是 HDI 要解的核心問題。
mSAP改良型半加成法，用電鍍長出極細線路、避免蝕刻側蝕；用於類載板、光模組 PCB。
CP 晶圓針測晶圓切割前，用探針卡逐顆量測晶粒電性，篩出 KGD。見 探針卡。
KGDKnown Good Die，已知良好晶粒。多晶粒封裝裡一顆壞就整包報廢，所以進封裝前要先篩好。
FT 成品測試封裝後的必要測試，依序做直流、功能、交流測試，並依速度分級（binning）。見 半導體測試。
SLT 系統級測試把晶片裝在接近真實主機板的測試板上開機跑軟體，抓 FT 抓不到的系統性與間歇性問題。
Burn-in／WLBI高溫高壓老化測試，逼出早夭瑕疵；WLBI 是在晶圓階段就做，HBM 最常見。
Shifting left把篩選往測試流程前段（晶圓測試）移，避免壞晶粒進入昂貴封裝。
ATE自動測試設備，俗稱測試機；送出測試訊號、比對晶片回應。Advantest、Teradyne 為主。
Handler分選機。FT／SLT 時把封裝好的晶片壓進測試座、依結果分盤；CP 用的是探針台（Prober）。
ATCActive Thermal Control，主動溫控。整合在 Handler 上，晶片跑負載時即時抽熱或加溫，維持測試溫度。
Load Board／DIB成品測試用的測試介面板，上面焊測試座、下面接測試機。見 測試介面板。
MEMS 探針用半導體微影製程做的探針；pitch 低於約 50µm 時幾乎只能用它。
CPOCo-Packaged Optics，共同封裝光學：光學引擎封在交換器晶片旁。見 CPO。
DRAM動態隨機存取記憶體，斷電資料消失，放在處理器旁當工作記憶體；靠製程微縮提升產出。見 DRAM / NAND 頁。
NAND Flash斷電不消失的快閃記憶體，用來做 SSD；靠堆疊層數提升容量。TLC 每格存 3 bit、QLC 存 4 bit。
eSSD企業級 SSD，資料中心用的固態硬碟。
LTALong-Term Agreement，長期供貨協議。記憶體廠與 hyperscaler 簽訂，常附預付款；HBM 一般不納入（輝達例外）。
Logic dieHBM 最底層的邏輯晶片（base die），用晶圓代工製程生產；HBM4 起其製程速度決定 HBM 效能。
8H / 12H / 16HHBM 堆疊幾層 DRAM core die。層數越多容量越大、良率越難。
Trade ratio做出同樣 bit 數的 HBM 要消耗幾倍標準型 DRAM 產能；分析師估 HBM4E 約 4:1。
Hybrid bonding混合鍵合，上下晶片以銅對銅直接接合、不用凸塊，可讓堆疊更薄、層數更高；預期 HBM5 起導入。
6F² / 4F²DRAM 記憶單元面積的表示法（F 為最小線寬）。主流大廠走 6F² + hybrid bonding；4F² 需垂直通道電晶體，難度高。
先進封裝把多顆晶片整合在一起的技術總稱，CoWoS 是其中一種。
