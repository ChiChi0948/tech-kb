測試介面板 Load Board · TIB

測試機（ATE）的接腳又粗又固定，晶片的接點又細又各不相同。測試介面板就是中間那塊「轉接板」：把測試機上千個通道，一路縮小、重新排線到晶片腳位上，還不能讓訊號失真。它常被忽略，但每一代新晶片都要重新設計一塊。

這是什麼

所有接觸元件（探針、測試座的針）都需要一塊板子來裝，這一類板子統稱測試介面板（Test Interface Board，TIB）。名稱很容易搞混，照 Technoprobe 的定義：

探針卡 PCB（PCIB）晶圓測試（CP）用。探針卡最底層的大圓板或方板，必要時加上空間轉換層（MLC 陶瓷或 MLO 有機）後，才裝探針頭。
PIB可有可無的轉接板，夾在測試頭與探針卡之間，用來重新分配測試機資源或解決平台不相容；探針卡原生設計給該測試機時就不需要。現在很多人也把探針卡 PCB 叫作 PIB。
DIB／Load Board成品測試（FT）用，又叫 DUT board。上面焊測試座，下面接測試頭上千個通道；交貨時是裝好上千顆零件、電性驗證過的整組，不是一塊空板。
Burn-in Board（BIB）老化測試用。一塊大板子焊幾十顆 Burn-in 測試座，整塊推進烤箱，在 125°C 以上撐幾小時到幾天。

訊號怎麼走

晶圓測試測試頭（pogo tower）→ PIB（不一定有）→ 探針卡（PCB ＋ 空間轉換層 ＋ 探針頭）→ 晶圓
成品測試測試頭 → DIB／Load Board → 測試座 → 接觸元件 → 晶片

每一層結構的工作都是「空間轉換」：把測試機毫米級的粗腳距，縮到晶片 pad 的 40–100µm 或封裝錫球 100µm 以上，同時保住訊號完整與供電。

Socket 和 Load Board 是一組 · 測試座直接焊在 Load Board 上，兩者一起設計。每顆新晶片放量，就要重新設計一組 Load Board ＋ Socket——所以 精測（Load Board）、穎崴（Socket）的營收會跟著客戶新品週期跳動，且常常一起接單。（凱基訪談，2026.06）

探針卡 PCB 的細腳距由空間轉換層吸收，所以板子本身可用一般通孔、單次壓合；難在層數與平整度（上萬根針同時下壓，表面差幾十微米就接觸不良）。Load Board 沒有中間層，測試座的針直接落在板面，逃線、GHz 阻抗控制、大電流、上千顆零件全部搶同一份層數預算，常常要盲埋孔與多次壓合，驗收標準是阻抗、損耗與通道校準。

為什麼比一般 PCB 難

設計目的不同。產品板是為量產設計：一個設計複製幾十萬到幾百萬片，追求低成本與良率。測試板是「量測儀器」：要把測試機的能力不失真地延伸到晶片腳位，還要撐過幾十萬次插拔或好幾天高溫，所以效能與精度優先、成本其次，同一個設計通常只做幾片。板子本身多一點損耗、阻抗偏差或熱變形，就會誤判——好晶片被打成壞的，或壞晶片被放行。

層數多好幾倍。一塊測試板要把測試機上千個通道，全部做阻抗控制、等長走線，收斂到幾公分見方的晶片範圍內；板子又縮不小（要配合測試機尺寸與機械強度），只能往厚度和層數要空間。

製程與材料。一樣是減成法壓合與機械鑽孔，但鑽孔深寬比要求高得多，高階板通常要背鑽。材料上，消費電子用標準 FR4、高階伺服器用低損耗板材（M6／M7 以上），探針卡 PCB 與 Load Board 則是低損耗與 FR4 混壓、只有高速層用頂級材料；BIB 不管速度、只管耐熱。延伸閱讀：PCB、HDI、CCL。

ATE 有標準訊號通道（例如 Advantest V93000 上有 1,024–2,048 個），但每顆晶片腳位排列都不同，Load Board 就是把標準通道重新路由到這顆晶片的對應腳位。AI 晶片腳位動輒兩三萬支，層數越多、走線與隔離空間越大，這也是精測的 Load Board 單價從 Blackwell 到 Rubin 大幅上漲的原因。（凱基訪談，2026.06）

市場與商業模式

  • 規模：DIB 約占測試介面市場 17%，2024–25 年約 9–10 億美元，2020 年是 5 億多美元（TechInsights）。Yole 估 2025–30 年測試介面板 CAGR 4.9%，是所有測試介面類別中最低的。
  • 不是賣板子，是賣工程解決方案：測試板供應商從設計、製造、組裝到校準一條龍（也有人把製造外包、走類 IC 設計公司模式），毛利率常見 30–50%；一般量產 PCB 廠靠規模與良率，毛利 10–30%。
  • 需求跟著換代走：每一代晶片、每一次封裝改變都要新設計一塊，需求不綁在單一產品的出貨量上。
  • 新進者難：一般 PCB 廠想跨進來，除了技術門檻，還要打進各大 IC 設計公司長期合作的供應鏈，而晶片換代又快，新廠缺少實績。

兩派供應商

自有派（測試機／探針卡大廠旗下）Advantest 把 R&D Altanova（測試板）、Essai（測試座）、Shin Puu（測試板 PCB）整合成 AIS，綁 V93000 測試機生態系、主攻旗艦處理器 Load Board。Technoprobe 收購 Harbor Electronics 與 Teradyne 的 DIS 部門，自己掌握探針卡 PCB 平整度良率。優勢是與測試機、探針頭一起設計、效能調到最好；缺點是用 Teradyne 測試機的客戶，可能不想跟 Advantest 買板子。
獨立派不綁任何測試機品牌，依區域晶片生態聚集。台灣：精測（供頂尖 IC 設計與晶圓代工）、雍智（Keystone Microtech，偏設計服務、製造外包）。韓國記憶體鏈：TSE、Daeduck，跟著 HBM 週期走。中國：Fastprint 全品類。北美與東南亞：Gorilla Circuits、Esa Electronics。優勢是中立、客製化快。
精測2025 年營收 48.06 億元，探針卡 65%、Load board／BIB／SLT 板 25%；探針卡 PCB／Load Board 產能 1Q27 是 2025 年底的 3 倍，Fab 3 預計 2028 年量產。凱基訪談：輝達 Rubin 世代 Load Board 份額從 Blackwell 的 25% 升到 70%。
雍智2025 年營收 21.36 億元，Load board／BIB／SLT 板 61.6%、探針卡 36.5%；無自有板廠，以研發資源整合與駐廠服務著稱。
